Privacy Policy: Quran: The Noble Book

Last updated: September 18, 2026

Quran: The Noble Book is a reader for the Quran. It collects nothing. There are no accounts, no ads, no trackers, no analytics, and no crash reporting. It is free and open source.

What leaves the device

Almost nothing. The app has one network use, and it happens only when the reader asks for it: downloading a content pack (a translation, a tafsir, a word list, a reciter's timings) or a recitation package for one surah, from the project's own GitHub Releases at github.com/muntasimulhaque/quran. That request carries nothing but the request itself: no account, no identifier, and no usage data. GitHub, like every web server, sees the connecting IP address; the app sends nothing else, and the project stores nothing.

Nothing is downloaded at launch. Nothing is downloaded automatically. A download starts only after the reader sees the item's name and size and taps to accept it. Every pack and every recitation package is verified against a SHA-256 recorded at build time, and anything that fails the check is discarded.

What stays on the device

  • The reading position, the theme, the text size, the chosen translation, tafsir, and reciter, bookmarks, and notes are stored in the app's private storage and never leave it.
  • Downloaded packs and recitation packages live in the app's private storage. Removing a pack, or a surah, deletes its files.
  • The app works fully offline: the Quran text and its page layout ship inside the app, and so do search, bookmarks, and notes. Anything the reader has already added works with no connection.

Permissions

  • INTERNET: the one use described above.
  • POST_NOTIFICATIONS: the media notification while a recitation plays.
  • FOREGROUND_SERVICE and FOREGROUND_SERVICE_MEDIA_PLAYBACK: keeping a recitation playing with the screen off.

Nothing else is declared.

Children's privacy

The app is suitable for all ages. It has no user accounts, no user to user features, no advertising, and no purchases, and it collects no personal information from anyone, including children.

Changes

If this policy ever changes, the change will appear on this page and in the project's repository history.
